# Rao Ventures Website

Official website for [Rao Ventures LLC](https://raoventures.co) — a holistic wellness and innovation company.

Built with pure HTML, CSS, and JavaScript. Hosted on GitHub Pages.

## Products

- **[Svastha](https://svastha.co/)** — Ancient Wisdom for Modern Life. Hindu scripture study with AI-powered guidance.
- **[Flow Into Stillness](https://flowintostillness.com/)** — Your Sanctuary for Inner Peace. Yoga platform with 50+ poses (new poses added weekly).
- **[My Ashtanga Yoga Practice](https://ashtangapractice.com/)** — Authentic Sanskrit audio guidance & guided Mysore practice mobile app for iOS and Android ([Website](https://ashtangapractice.com/) | [App Store](https://apps.apple.com/us/app/my-ashtanga-yoga-practice/id6794335298) | [Google Play](https://play.google.com/store/apps/details?id=com.ashtangapractice.app)).
